# Data directory / 数据目录

This public repository intentionally contains no audio, transcripts, speaker embeddings, datasets, checkpoints, or generated outputs.

本公开仓库不包含任何音频、台词、说话人特征、数据集、检查点或生成结果。

For private experiments, use audio and text that you own or are explicitly authorized to use. Keep private material outside this repository and never remove the protective patterns from the root `.gitignore` without reviewing the publication boundary.

个人实验只能使用自有或明确获得授权的音频和文本。请将私有素材放在本仓库之外；修改根目录 `.gitignore` 前必须重新检查公开边界。
